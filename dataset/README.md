# Dataset

```
dataset/
├── raw/                    # 7 raw source datasets (unmodified inputs)
├── sample_dataset.csv      # 5,000-row stratified sample of merged data (versioned)
├── cleaned_dataset.csv     # (git-ignored, ~535 MB) regenerated by `python main.py`
└── merged_dataset.csv      # (git-ignored, ~515 MB) regenerated by `python main.py`
```

## Overview

The full dataset is produced by merging 7 public email corpora into a single
unified CSV. Each row is one email with a binary label:

- `label = 1` — Phishing / spam
- `label = 0` — Legitimate email

Full dataset totals (164,972 emails):

| Label | Count  |
|-------|--------|
| 0 (legit)     | 79,190  |
| 1 (phishing)  | 85,782  |

`sample_dataset.csv` is a 5,000-row stratified subset of the merged dataset
(sampled per source and label, seeded for reproducibility). It is small enough
to version in git so the raw pipeline output is always reproducible.

## Columns

All datasets are normalized to a common schema by `DatasetLoader`
(`src/preprocessing.py`):

| Column          | Description                                        |
|-----------------|----------------------------------------------------|
| `text_combined` | Full email text (subject + body)                   |
| `subject`       | Email subject line (may be empty)                  |
| `body`          | Email body (may be empty)                          |
| `sender`        | Sender address (may be empty)                      |
| `label`         | `0` = legitimate, `1` = phishing                   |
| `source_dataset`| Name of the originating raw dataset                |

## Cleaning

`TextPreprocessor` (`src/preprocessing.py`) applies, in order:

1. Lowercase
2. Remove HTML tags
3. Remove URLs
4. Remove email addresses
5. Remove signature/quote blocks
6. Remove punctuation
7. Remove numbers
8. Remove emojis
9. Tokenize
10. Remove stopwords
11. Lemmatize (WordNet)
12. Rejoin tokens

The cleaned output is cached in `cleaned_dataset.csv`. Note that
`merged_dataset.csv` holds the schema-unified but **uncleaned** text, while
`cleaned_dataset.csv` holds the NLP-cleaned text used for training.

## Regenerating the large files

```bash
python main.py            # merges + cleans + trains (reuses cleaned cache)
python main.py --no-clean # force re-merge and re-clean from raw/
```

The two large CSVs are git-ignored (`.gitignore`) and regenerated on demand;
only `raw/` and `sample_dataset.csv` are versioned.
